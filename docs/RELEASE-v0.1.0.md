# PSAI v0.1.0

首个正式版本，为 Steam 版《深空当铺：可能是偷的》提供原生模组与共用的 CLI / MCP 接口。

## 兼容与使用

- 验收游戏为 0.46D、VERSION 100-Rev13，Steam build 26525552。模组保留版本校验及原版扫描。
- 开发与运行环境为 Windows、PowerShell 7、项目指定的 .NET SDK 和 Node.js 24。构建引用玩家本机游戏程序集。
- 安装、CLI 与 MCP 配置见 README。协议版本继续为 0.1，工具保持 status、observe、inspect、actions、act、result 六个入口。
- 默认指导为第 5 版，可通过本机偏好配置覆盖。当前顾客独立通缉身份是明确开放的内部字段，结果标记来源，其他信息主要来自可见面板与原版说明。

## 已验证能力

- 基础营业、手动对白与选择、正常买卖、预算不足确认、批量交易、日结及选项恢复。
- 固定与便携容器、嵌套内容、可见性隔离、原版容量和类型拒绝、交易期间的自有容器读取。
- 机器面板与槽位、水培实际生产、正常材料升级、通用物品间使用及液体灌装和品质继承。
- 电话对白与选择、名片号码读取和关闭、加点专用币校验及显式现金补差。
- 选包总容量、常驻背包读写与物品带回、三个外出地点入口、垃圾场搜索与科技商店购买、原版外出次数耗尽后拒绝再次出发。
- 霰弹枪举起和放下、射击目标校验、原版确认死亡及治安部后续对白完整收尾。
- 会话与状态版本校验、命令去重、超时查询，以及 CLI / MCP 共用传输和指导。

## 后续验收项

票券足够时的配给站实际购买、NPC 证书购买与物品提交、工具取出卡住模组、通缉正例与实际举报、机器单选和滑块实机操作，以及鉴定和教程专项继续按样本验收。配给站商品、价格、库存、按钮关联及不足票券条件已验证。

本版本依靠原版合法空位搜索移动物品，精确格子摆放与旋转仍待扩展。操作回执表示处理函数返回，动画、对白和最终效果需继续观察。

详细验收记录见 docs/STATUS.md，原始实机回执保存在本机被忽略的 artifacts/live 目录。首版发布标记对应本仓库 v0.1.0 标签。
