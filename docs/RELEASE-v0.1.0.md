# PSAI v0.1.0

为 Steam 版《深空当铺：可能是偷的》提供原生模组与共用的 CLI / MCP 工具。

## 兼容与接口

- 适配游戏 0.46D、VERSION 100-Rev13，验收 Steam build 26525552。
- Windows，工具使用 Node.js 24；从源码构建需要 PowerShell 7 和项目指定的 .NET SDK。
- 协议版本为 0.1，保持 status、observe、inspect、actions、act、result 六个入口。
- 当前默认指导以运行时 guidance 为准，支持本机偏好覆盖。安装与接入见 README，操作详情见接口说明。

## 能力

基础营业、对白与选择、正常买卖及议价、批量交易、报告、可见库存与容器、机器槽位和控件、物品间使用与加工、电话与加点、外出与随身容器均通过原版交互流程接入。顾客上下文、队列、需求、实际出售候选、以物易物条件和原版报价行由当前状态提供。

当前源码增加了香烟、机械手、肋明治、燃料匣的鉴定窗口读取、原版控件、估值输入和按需局部图像。该扩展的离线检查与实机覆盖分别记录，不把编译通过视为所有鉴定样本均已实测。

通缉身份开放原版独立字段并标记来源；举报、射击与消费动作仍需根据当前目标、用户指令和原版条件决定。

物品移动使用原版合法空位搜索；精确格子摆放与旋转尚未提供。图案判断可能需要查询局部图像，鉴定不提供隐藏正确答案。动作回执表示处理函数返回，最终效果需要继续观察。

历史 v0.1.0 标签保留首次发行内容；当前分支中的后续修复以当前代码及运行时能力为准。
