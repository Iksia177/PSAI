# PSAI v0.9.1

本版本补齐前期提示和设置窗口的信息交付，继承 v0.9.0 的接口与兼容范围。

- 展示柜陈列生效时间提示直接读取原版当前文本，避免新弹窗首帧文字漏读，并关联确认动作。
- 补充对白设置、游戏设置及教程提示的文字和原版按钮；设置窗口提供正常关闭入口，保留可识别的原版按钮附带回调。
- 观察、动作结果和延迟回执查询均在顶层返回 attention，提供待回应窗口、文字、控件与阻塞状态；指导通过 focus 提醒先处理当前窗口。
- 区分需要回应的窗口与普通教程说明，不自动确认消费、提交或剧情决定，不统一跳过教程。

工具、MCP 和游戏模组版本统一为 0.9.1；协议保持 0.1，六个工具入口不变。请同步更新 agent 工具与游戏模组，并重启游戏和 MCP 服务。

离线检查覆盖类型检查、构建、25项自动测试、原版接口元数据检查及模组扫描。实际弹窗和教程流程的验收由后续游玩继续完成；本版本不代表全部游戏系统已验证。
