# PSAI v0.9.3

补齐鉴定指南及同类文档的阅读接口，包含机械手、燃料匣和肋明治使用的原版多页阅读器。

- observe.documents 列出当前打开文档的正文、页码、翻页和关闭动作；inspect detail=document 查询当前可见页。
- 接入 MultiPageUIManager，支持原版上一页、下一页和关闭；补充普通书册、单页纸张、香烟/票券/注射器指南、色卡、密码本和相关说明页。
- 只读取已经正常打开的文档和当前可见页。图片或示意图无法用文本表达时，明确返回状态并提供当前页按需图像，不把空文本当作无内容。
- 打开的文档优先阅读；阻塞确认框仍优先处理。翻页或关闭后原页的图像上下文失效，避免复用旧页。

工具、MCP、模组和启动日志统一为0.9.3，协议仍为0.1。请同步更新工具和游戏模组，并重启游戏与MCP。

本版本通过离线构建与回归检查，指南页面的实际文字/图案覆盖仍需使用样本实测。已发布的GitHub Release附件和Steam工坊分别更新，以下载包标记及实际提交结果为准。
