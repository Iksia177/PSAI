# PSAI v0.9.2（预发布）

这是 PSAI 首个提供编译模组下载的 GitHub Release。项目已接入基本游玩流程，仍在验证更多机器、事件与组合场景；此版本标记为预发布，方便实际游玩和反馈。

## 本次更新

- 区分事件对白、对白选择与普通买卖，提供主要/次要动作分组。委员会等事件优先使用原版 choice，避免与送客、砍价和普通交易混淆，同时保留原版允许的操作。
- 确认弹窗优先于顾客对白；兼容旧模组回执中已返回的 choice，正常买卖仍沿用原流程。
- 包含设置窗口、教程提示、展示柜生效时间提示与顶层 attention 信息交付，以及按存档开放状态筛选的基础指导。
- README 已补 Steam 工坊订阅入口；发布配置保留已有工坊 ID，避免更新时重复创建条目。

## 下载与安装

1. 下载附件 `PSAI-Mod-v0.9.2.zip`。`SHA256SUMS.txt` 提供压缩包和模组文件的校验值。
2. 退出游戏，将压缩包解压到游戏安装目录的 `Mods/`，确认文件位置为 `Mods/psai/PSAI.Mod.dll` 和 `Mods/psai/manifest.xml`。
3. 在游戏模组菜单启用 PSAI，重启并载入存档。
4. Agent 侧同步更新本 GitHub 项目，按 README 安装 Node.js 24 依赖并配置 CLI / MCP；更新后重启 MCP 进程。

GitHub 自动附带的 Source code 是源码包，不是编译模组。通过 Steam 工坊安装时，以条目实际已发布内容为准；GitHub Release 和工坊更新分别提交，工坊审核不会自动发布之前失败的更新。

## 兼容与验证

适配 Windows、游戏 0.46D / VERSION 100-Rev13（验证 build 26525552）。工具、MCP 与模组版本为 0.9.2，协议保持 0.1，六工具入口不变。

类型检查、构建、28项自动测试及原版模组扫描通过。委员会事件的现场复测与其他系统覆盖继续进行，不保证所有机器和剧情分支均可正常使用。动作回执表示原版处理函数返回，最终结果仍应继续观察。
