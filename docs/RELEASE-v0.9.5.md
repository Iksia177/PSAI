# PSAI v0.9.5（预发布）

补齐检测工具使用后的结果窗口，让 agent 可以读取结果、按原版条件操作标签，并正常关闭窗口。

- 水质检测器、水质试纸（含使用后再次查看）、化学检测器及植物分析器返回 `tool_results`，包含当前文字、被测物名称和可用动作；也可用 `inspect detail=tool_result` 查询。
- 匹配标签、质疑和关闭调用原版流程，复验当前窗口及目标，不直接写入检测结果或绕过所有权条件。
- 接入标签机选项和名称标签编辑。修改展示标签不等于检测，仍由 agent 根据需要选择。
- 基因扫描器使用现有开关及悬浮说明接口，并返回当前扫描标记。
- 结果窗口进入 `attention` 和当前指导，优先读取结果再继续日常接客。结果关联不会将隐藏物品注册为可移动目标。

## 下载与安装

下载 Assets 中的 `PSAI-Mod-v0.9.5.zip`（校验值见 `SHA256SUMS.txt`）。退出游戏，将其中的 `psai` 文件夹复制至游戏目录 `Mods/`，启用模组并重启。Agent 侧同步更新项目并重启 MCP，进入可操作存档后再检查连接。Source code 为源码，不是编译好的模组。

沿用 0.9.4 的只读库存总览与闭合容器交易候选。协议仍为 0.1。编译、原版扫描和自动回归通过；新增检测、标签编辑及实际交易的实机验收尚待进行，不保证所有游戏系统兼容。工坊与 GitHub 分别发布，以实际安装版本为准。

如遇回归，可退出游戏并安装之前的 [v0.9.4](https://github.com/Iksia177/PSAI/releases/tag/v0.9.4) 模组包，agent 工具也切换到对应标签。替换模组不会撤销已写入存档的游戏操作，测试请保留存档副本。
