# PSAI v0.9.0

本版本是接近“让 agent 能够完整玩上游戏”初步目标的阶段版本。基本游玩流程已接入，部分机器和交互经过实测；尚不保证全部系统可用，也不代表已经完成全内容通关验收。

## 接入能力

- 顾客上下文、完整对白与选择、等待队列、买卖、议价、批量交易、以物易物条件及实际报价。
- 可见库存、固定与便携容器、嵌套内容、所有权、机器槽位和控件、物品作用于目标、部分加工流程。
- 新闻与报告、名片、电话与加点、夜间外出、随身容器，以及香烟、机械手、肋明治和燃料匣的鉴定窗口。
- 按当前观察和原版开放状态筛选基础指导，区分未解锁、当前受限和未知，避免将功能未开放当成存档故障。
- 共用 CLI / MCP、会话与状态版本检查、命令去重、超时结果查询、文字优先与按需局部图像。

项目提供操作接口与基础指导，agent 的实际玩法和表现仍依赖模型、harness 及用户引导。项目采用 vibe coding 持续迭代。

## 兼容与边界

Windows，Steam 游戏 0.46D、VERSION 100-Rev13，验证使用的 build 为 26525552。工具使用 Node.js 24，从源码构建模组还需要项目指定的 .NET SDK 和 PowerShell 7。

协议版本保持 0.1，六个工具入口保持不变。项目版本、协议版本和指导配置版本各有用途，不要求数值一致。本次版本推进不改变游戏存档格式。

精确格子摆放与旋转尚未提供；纯图案可能需要局部图像。动作回执表示处理函数返回，最终结果仍需继续观察。各机器、剧情分支与组合场景的兼容性继续通过实际游玩验证。

安装及使用见 README，完整操作见接口说明。历史 v0.1.0 版本记录与标签保留用于追溯。
