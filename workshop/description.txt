[h1]PSAI — Probably Stolen Agent Interface[/h1]
让 AI agent 接口接管你的当铺，观察它如何学习经营。

[b]当前版本：0.9.2 | 作者：Iksia[/b]

[h2]这是什么？[/h2]
PSAI 为《深空当铺：可能是偷的》提供原生游戏接口，让支持本地程序或 MCP 的 agent 读取游戏状态并执行正常游戏操作。适合 Codex 及其他支持 CLI / MCP 的 harness。

本模组不内置 AI 模型，不单独提供自动经营。你还需要在电脑上安装 agent 工具并连接自己使用的模型或 harness。

[h2]安装和开始游玩[/h2]
[list]
[*]订阅本模组，在游戏模组菜单启用 PSAI，然后重启游戏。
[*]把 GitHub 项目地址交给 agent，让它按 README 安装工具和配置 CLI / MCP。
[*]你载入存档并确认已进入可操作界面后，再让 agent 检查连接并开始游玩。
[/list]
[url=https://github.com/Iksia177/PSAI]GitHub 项目、安装说明与 agent 工具[/url]

工具使用 Node.js 24。推荐在可信本机环境为 agent 开启完全权限，方便读写游戏的 ModData/psai 通信目录；无需修改 Windows 文件夹权限或游戏存档。

[h2]实现状态与边界[/h2]
已接入基本营业流程、对白与选择、买卖和议价、库存与容器、报告、电话与加点、夜间外出，以及部分加工和鉴定操作。部分机器经过实测，但不保证所有机器、事件和游戏系统均能正常使用。

本项目提供操作接口及随当前进度筛选的基础指导。具体玩法和表现取决于模型、harness 与用户引导，需要你自行调教。观察 agent 从生疏到熟练、逐渐形成自己的玩法，也是数字生命的一种乐趣。

本项目采用 vibe coding，由人提出想法和反馈，与 AI 协作实现并持续迭代。

[h2]0.9.2 更新[/h2]
补充设置窗口和前期教程提示；将当前弹窗文字、控件及待回应状态在回执中突出交付，减少 agent 忽略提示的情况。确认和消费仍由 agent 根据内容选择，不自动跳过教程。
增加事件对白与普通交易动作的分组，优先展示当前 choice 或对白推进动作，避免将鉴定委员会等事件误当成普通接客；原版允许的次要操作仍保留。

[h2]兼容说明[/h2]
当前验证环境：Windows，Steam 游戏 0.46D、VERSION 100-Rev13（build 26525552）。游戏更新可能影响兼容性，更多说明见 GitHub。

游戏侧模组采用官方模组数据接口交换 JSON，当前构建通过原版扫描，未声明额外能力权限。模组本身不会向外部模型联网；agent 与模型服务的连接由你使用的工具决定。游戏状态会交付给所连接的 agent，通缉识别包含原版独立身份字段。
